# 📚 MASTER STRUCTURED TECHNICAL LEARNING ROADMAP
### Step-by-Step Curriculum for Daily 60-Minute Block 2 Practice

---

## 📑 MODULE 1: ADVANCED SQL & DATA QUALITY AUDITING
* **Topic 1.1:** Deduplication with `ROW_NUMBER() OVER (PARTITION BY ... ORDER BY ... DESC)`.
* **Topic 1.2:** Snowflake Native `QUALIFY` clause vs. ANSI SQL CTEs.
* **Topic 1.3:** Data Completeness & Null Audit Queries (`COUNT(*) - COUNT(col)`).
* **Topic 1.4:** Advanced Aggregations with `GROUP BY`, `HAVING`, and Window Functions (`DENSE_RANK`, `LEAD`, `LAG`).

---

## 📑 MODULE 2: DATA GOVERNANCE & COMPLIANCE PILLARS
* **Topic 2.1:** The 5 Core Data Governance Pillars (Quality, Stewardship, Privacy, Lineage, Compliance).
* **Topic 2.2:** Dynamic Data Masking (DDM) for PII security (`Credit_Card`, `SSN`).
* **Topic 2.3:** Row-Level Security (RLS) vs. Object-Level Security (OLS).
* **Topic 2.4:** Audit Trail Tables & Exception Logging Frameworks (`Error_Log_Table`).

---

## 📑 MODULE 3: DATA ARCHITECTURE & MEDALLION LAYERS
* **Topic 3.1:** Bronze Layer (Raw Data Ingestion / Landing Zone).
* **Topic 3.2:** Silver Layer (Data Cleansing, Validation, Type Casting, Deduplication).
* **Topic 3.3:** Gold Layer (Star-Schema Modeling, Fact & Dimension Tables, Business Aggregations).
* **Topic 3.4:** Governance Implementation by Layer (Security at Storage, Quality at ETL, Metrics at Semantic).

---

## 📑 MODULE 4: POWER BI ARCHITECTURE & DAX ENGINE (VERTIPAQ)
* **Topic 4.1:** VertiPaq Engine Optimization (High Cardinality Reduction, Splitting DateTime).
* **Topic 4.2:** DAX Filter Context Management & `KEEPFILTERS()`.
* **Topic 4.3:** Power BI 4 Workspace Roles (Admin, Member, Contributor, Viewer).
* **Topic 4.4:** Import vs. DirectQuery vs. Fabric Direct Lake Storage Modes.

## 📑 MODULE 5: BUSINESS REQUIREMENT SPECIFICATIONS & METRICS
* **Topic 5.1:** BRD (Business Requirements Document) vs. FRS (Functional Requirements Specification).
* **Topic 5.2:** KPI (Key Performance Indicator) vs. KRI (Key Risk Indicator) vs. SLA/KIS.
* **Topic 5.3:** Stakeholder Management & Conflict Resolution (Fact-Based Data Auditing).
* **Topic 5.4:** Incident Management & Jira Ticketing Workflows.

---

## 📑 MODULE 6: SNOWFLAKE ARCHITECTURE & DATA ENGINEERING
* **Topic 6.1:** Snowflake Architecture (Storage, Compute Virtual Warehouses, Cloud Services).
* **Topic 6.2:** Micro-Partitions & Automatic Clustering Keys.
* **Topic 6.3:** Streams & Tasks for Change Data Capture (CDC) / Medallion Pipelines.
* **Topic 6.4:** Snowflake Cost Optimization & Performance Tuning.
