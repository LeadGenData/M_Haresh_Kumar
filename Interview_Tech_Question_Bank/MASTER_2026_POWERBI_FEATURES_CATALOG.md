### Verified Technical Reference Document for Senior BI Lead Interviews

## 🚀 OVERVIEW: THE 2026 STRATEGIC SHIFT
In 2026, Microsoft officially shifted Power BI from a desktop-dependent tool into a **cloud-native, web-based, code-first modeling environment**. Developers can now author TMDL, edit DAX measures, manage DirectQuery settings, and leverage Copilot AI directly inside the Power BI Web Service (`app.powerbi.com`).

---

## 📅 MONTHLY FEATURE BREAKDOWN (2026)

### 1. 🗓️ JULY 2026: TMDL Web View & Cloud Governance
* **TMDL (Tabular Model Definition Language) on the Web:** Allows developers to inspect, script, and edit semantic model objects directly in the browser using clean human-readable code.
* **Model Options in Service:** Settings like relationship auto-detection, type detection, and DirectQuery connections are now configurable directly in Power BI Service without opening Power BI Desktop.
* **Organizational App Audiences (GA):** Granular audience security controls inside Power BI enterprise apps.

---

### 2. 🗓️ JUNE 2026: AI Copilot & DAX Query View Grid Filtering
* **Copilot in Web Modeling:** Developers can create, modify, and optimize semantic models using natural language prompts directly in the web browser.
* **DAX Query View Grid Filtering & Sorting (GA):** Allows direct interactive filtering, sorting, and inline debugging within the DAX query execution results grid.
* **DAX User-Defined Functions (UDFs - GA):** Reusable custom functions written in DAX without repeating complex measure logic.

---

### 3. 🗓️ MAY 2026: Visual Calculations & Native Slicers
* **Visual Calculations (General Availability):** Allows running totals, moving averages, and period-over-period variance calculations created directly on a visual container without bloating the underlying semantic model.
* **Input Slicer Support:** Enhanced native parameter slicers for dynamic scenario modeling.

---

### 4. 🗓️ APRIL 2026: Fabric Direct Lake & Git Integration
* **Fabric Direct Lake Security Alignment:** Automatic passthrough of Row-Level Security (RLS) and Object-Level Security (OLS) from OneLake Iceberg/Delta tables to Power BI semantic models.
* **Native TMDL Git Integration:** Seamless multi-developer branching, pull requests, and CI/CD deployment pipelines using TMDL files.

---

### 5. 🗓️ MARCH 2026: DAX Query View `///` Metadata Comments
* **`///` Triple-Slash Comments:** Native documentation syntax directly above `DEFINE MEASURE` in DAX Query View. Automatically enriches Copilot context and Q&A engines while exporting metadata to TMDL.
