💳 1. Snowflake Medallion Data Pipeline & Fraud Analytics

Business Problem

Financial teams face high volumes of raw credit card transaction logs across multiple file formats (JSON, CSV). Manual processing leads to delayed reporting, duplicate records, and exposure of sensitive customer PII.

Architecture Diagram
Raw Transactions (JSON / CSV) ──> Bronze (Staging) ──(Streams & Tasks)──> Silver (De-duped & PII Masked) ──(Star Schema)──> Gold (Fact/Dim Tables) ──> Power BI Dashboard
Key Practical Outcomes
  • Real-Time Automated Ingestion: Continuous file processing via Snowflake Streams replaced manual batch processing.
  • Data Privacy Compliance: Dynamic Data Masking automatically anonymized credit card & account numbers for BI visualizers.
  • Data Integrity: Applied `QUALIFY ROW_NUMBER()` in Silver layer to guarantee 0 duplicate log records.

📧 2. Multi-Account Outlook Email Automation & CRM Sync

Business Problem

Daily outbound lead campaigns required manual dispatching across multiple Outlook accounts, risking provider ban limits, missing bounce emails, and leaving CRM records un-updated.

Architecture Flow
Google Sheets API Contacts ──> Python Rotator Engine ──> Outlook COM API (Account 1 & 2) ──> Bounce Parser ──> CRM Writeback
Key Practical Outcomes
  • Automated Dispatch: Eliminated manual email sending and status logging.
  • Provider Safety: Enforced strict 100 emails/day cap per profile with automated profile rotation.
